# Welcome to My Levenshtein Data
***

## Task
Compare two strings and count how many characters are different between then.

## Description
My_levenshtein returns -1 if the string differ in lenth, otherwise it counts the differing characters.

## Installation
No installation needed, jusy python 3 and the file ex00/my_levenshtein.py.

## Usage
```
Call my_levenshtein("ACCAGGG", "ACTATGG") and it returns 2.
```
