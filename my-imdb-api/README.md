# My Imdb Api

## Task
Build a backend API that serves movies from a CSV file filtered by genre.

## Description
The Flask app in app.py parses the CSV, filters the movies by genre, and answers in JSON on port 8080.

## Installation
Install Python 3 and Flask with pip install flask, and keep the CSV file next to app.py.

## Usage
Run python3 app.py, then use curl "http://localhost:8080?genre=action" or the route /comedy.
