# Qwasar DevOps Journey

My learning journey through Qwasar Silicon Valley's software engineering program, focused on DevOps, systems programming, and data engineering. This repository tracks every quest and project I complete, with the code, tests, and lessons behind each one.

## About this repository

This is a personal learning log. Each folder is a self-contained quest or project, graded against Silicon Valley engineering standards by automated tests. I commit small and often so the history reflects the actual progression.

## Skills developed

- **C systems programming:** pointers, manual memory management, strings, structs, variadic functions, system calls
- **Python for data:** scraping, cleaning, transforming, and serving data via Flask
- **Git & GitHub:** branches, merges, conflict resolution, multi-remote workflows
- **Debugging:** reading error messages and test reports to isolate problems quickly
- **Documentation:** clear READMEs and commit messages so the work speaks for itself

## Workflow

Every quest follows the same loop:

1. Read the subject and understand the expected behavior
2. Write the function with a small `main` in `/tmp` to test locally
3. Run automated tests (Gandalf for Qwasar) until everything passes
4. Commit per exercise with a clear message
5. Push to both the Qwasar remote and my personal GitHub
