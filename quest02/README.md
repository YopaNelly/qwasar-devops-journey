# Quest02

## Task
Learn how pointers work in C and practice string functions and simple arithmetic functions.

## Description
Each exercise is a small C function, such as my_swap with pointers, my_strlen, my_putstr, my_upcase and my_downcase.

## Installation
Compile any file with gcc and add your own main in a separate test file, because the exercises contain only functions.

## Usage
Call the functions from a main, for example my_swap(&a, &b) swaps two integers using their addresses.
