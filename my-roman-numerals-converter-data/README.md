# Welcome to My Roman Numerals Converter Data
***

## Task
Convert a normal number into a Roman numeral string, for example 14 becomes XIV.

## Description
my_roman_numerals_converter goes through a list of Roman values from 1000 down to 1 and adds each symbol as many times as it fits.

## Installation
No installation needed, just Python 3 and the file ex00/my_roman_numerals_converter.py.

## Usage
Call my_roman_numerals_converter(2022) and it returns the string MMXXII.
```
./my_project argument1 argument2
```
